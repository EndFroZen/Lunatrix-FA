## Lunatrix คืออะไร

Lunatrix เป็นแอปสำหรับขีดเขียนลงบนหน้าจอได้ทันที เช่น ระหว่างดู YouTube สอนงาน พรีเซนต์ หรืออธิบายอะไรบนจอให้คนอื่นดู
แอปจะอยู่ในถาดระบบเงียบ ๆ ไม่กินที่บนจอ เมื่อต้องการใช้ก็กดปุ่มลัดหรือคลิกไอคอน แล้ววาดทับหน้าจอได้เลยโดยวิดีโอและโปรแกรมด้านหลังยังทำงานตามปกติ

สร้างด้วย [Tauri 2](https://tauri.app) (Rust + HTML/JS) ตัวโปรแกรมจึงเล็กและใช้ทรัพยากรน้อย

## ความสามารถ (กำเมือง)

### ✏️ ขีดเขียนบนจอได้ตึงหมด
กดปุ่มลัดเตื่อเดียว จอก็กลายเป็นกระดานหื้อขีดเขียนได้เลยเจ้า จะเปิด YouTube ฟังเพลง หรือเปิดงานอะหยังอยู่ก็ขีดทับได้หมด
วิดีโอบ่ค้าง บ่ขาว ยังเล่นไปตามปกติ

### 🛠️ เครื่องมือมีหลายอย่าง
- **ปากกา** – ขีดเส้นเรียบ ๆ ลื่น ๆ
- **ดินสอ** – เส้นหยาบ ๆ เหมือนไส้ดินสอแต้ ๆ
- **ลูกศร** – ชี้หื้อหันว่าตรงไหนสำคัญ
- **สี่เหลี่ยม** – ตีกรอบล้อมสิ่งที่อยากหื้อผ่อ (กด Shift ค้างไว้ได้สี่เหลี่ยมจัตุรัส)
- **วงกลม** – วงล้อมจุดที่สำคัญ (กด Shift ค้างไว้ได้วงกลมกลมดิกเลย)
- **ยางลบ** – ลากผ่านเส้นใด เส้นนั้นหายไปตึงเส้นเลยเจ้า บ่ต้องมานั่งถูทีละหน่อย

### 🎨 สีกับขนาดเส้น
- มีสี่สี: แดง เหลือง เขียว ฟ้า
- ขนาดเส้นมีสี่ขนาด **S M L XL** ใจ้ได้กับเครื่องมือตึงหมด

### 🖱️ หน้าตาเมาส์บอกว่ากำลังใจ้อะหยังอยู่
เมาส์จะเปลี่ยนรูปตามเครื่องมือกับสีที่เลือก ผ่อปุ๊บก็ฮู้เลยว่าตอนนี้เป็นปากกา ดินสอ ลูกศร หรือรูปทรงอะหยัง สีอะหยัง

### 📌 แถบเครื่องมือซ่อนอยู่ข้างจอ
แถบเครื่องมืออยู่ทางซ้ายกลางจอ ปกติจะหุบเหลือเส้นบาง ๆ บ่บังหน้าจอ
เอาเมาส์ไปจ่อมันจะค่อย ๆ เลื่อนออกมา เอาเมาส์ออกมันก็ค่อย ๆ หุบปิ๊กไป
ตอนบ่ได้ขีดเขียน แถบจะหายไปเลย หน้าจอสะอาดเอี่ยม

### 🔀 โหมดใจ้จอปกติ (เส้นยังอยู่)
ขีดเสร็จแล้วอยากกดหยุดวิดีโอ เลื่อนหน้าเว็บ หรือคลิกอะหยังต่อ ก็สลับไปโหมดใจ้จอได้
เส้นที่ขีดไว้ยังอยู่บนจอ แต่เมาส์คลิกทะลุไปใจ้โปรแกรมข้างหลังได้ตามปกติเจ้า

### ↩️ ขีดผิดก็ย้อนได้
กดย้อนกลับได้ตึงการขีด การลบด้วยยางลบ และการลบทั้งหมด บ่ต้องย่านขีดผิด

### ⚙️ หน้าตั้งค่า
- เปลี่ยนปุ่มลัดเปิดปากกาได้ตามใจ๋ คลิกช่องแล้วกดปุ่มที่อยากได้ก็แล้ว
  ถ้าปุ่มนั้นมีโปรแกรมอื่นใจ้อยู่แล้ว แอปจะบอกหื้อฮู้
- เลือกได้ว่าจะหื้อแอปเปิดเองตอนเปิดคอมหรือบ่

### 🚀 เปิดพร้อมเครื่อง
เปิดคอมมาแอปก็ขึ้นมารออยู่ในถาดระบบแล้ว บ่ต้องมานั่งเปิดเอง

## ปุ่มลัด

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| `Ctrl` + `Alt` + `P` | เปิดปากกา / สลับโหมดวาดกับโหมดใช้จอปกติ (เปลี่ยนได้ในหน้าตั้งค่า) |
| `P` | ปากกา |
| `N` | ดินสอ |
| `A` | ลูกศร |
| `R` | สี่เหลี่ยม |
| `O` | วงกลม |
| `E` | ยางลบ (ลบทั้งเส้น) |
| `1` `2` `3` `4` | ขนาดเส้น S / M / L / XL |
| `Shift` ค้าง | สี่เหลี่ยมจัตุรัส / วงกลมพอดี |
| `Ctrl` + `Z` | ย้อนกลับ |
| `Esc` | ลบทั้งหมดและปิดการวาด |

> ปุ่มตัวอักษรใช้ได้ทั้งตอนเปิดแป้นพิมพ์ภาษาไทยและภาษาอังกฤษ

## การใช้งานจากไอคอนในถาดระบบ

- **คลิกซ้าย** – เริ่มวาด / สลับโหมด
- **คลิกขวา** – เมนู: วาด / ใช้จอ, ตั้งค่า…, ออก
